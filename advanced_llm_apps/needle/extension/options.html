needle.

Your grocery companion.
Across your tabs.

Start npm run dev from the Needle project folder, then connect to http://127.0.0.1:4199. Add your Vercel AI Gateway key and OpenAI API key to the project’s server-side .env file. Neither key belongs in the extension. Leave the app access token blank for local use.

Click the Needle toolbar icon on a webpage, or press ⌘⇧Y on Mac / Ctrl+Shift+Y elsewhere to search the current page with Needle.

Jev reads visible product details only from Woolworths and Coles pages after you grant access. Voice uses a separate live speech connection; the transcript is shown in the side panel. Chrome system pages and built-in PDF viewers are not supported by page search.
