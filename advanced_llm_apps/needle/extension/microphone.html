ONE-TIME SETUP

Allow Voice to use your microphone

Chrome can dismiss microphone prompts from the side panel. This full tab lets Chrome ask for access. Needle only checks that permission here; this setup page stops the microphone immediately and does not send audio to Voice.

Choose Allow if Chrome asks for microphone access.

If Chrome still blocks it

  1. Open chrome://extensions.
  2. Find Needle, choose Details, then Site settings.
  3. Set Microphone to Allow, then return here.
  4. On macOS, allow Google Chrome in System Settings → Privacy & Security → Microphone.
